# Sequential Decision-Making — MDP and Dynamic Programming Theory

Mathematical foundations for **Markov Decision Processes** and **Dynamic Programming**, synthesizing material from *Puterman*, *Bertsekas*, and *Sutton & Barto*. Pure theory — the probabilistic and operator-theoretic foundations upstream of any reinforcement learning algorithm.

## Structure
- **`01_Finite-Horizon-MDPs/`** — MDP definitions, induced stochastic process, backward induction, optimality equations.
- **`02_Infinite-Horizon-MDPs/`** — Discounted policy evaluation, Banach fixed-point theory, value iteration, Bellman operators, Policy Improvement Theorem.

All reports typeset in LaTeX. Algorithmic implementations live in the [`Reinforcement-Learning`](https://github.com/SaiSampathKedari/Reinforcement-Learning) and [`Deep-Reinforcement-Learning`](https://github.com/SaiSampathKedari/Deep-Reinforcement-Learning) repositories.
